Il codice di Karakara non è in questo repository: qui si raccolgono solo segnalazioni e idee.
*The Karakara source code is not here: this repository only collects reports and ideas.*

## Come aprire una segnalazione / How to report

1. **Issues → New issue**, poi scegli **Bug** o **Richiesta**.
2. Una segnalazione per problema: due problemi diversi = due issue.
3. Per un bug allega la diagnostica: in Karakara **Aiuto → Esporta diagnostica…**, poi trascina il file nella issue.
   Un video o uno screenshot aiutano molto.

*Open **Issues → New issue** and pick **Bug** or **Request**. One issue per problem. For bugs, attach the file from **Help → Export diagnostics…**; a video or screenshot helps a lot.*

## Privacy

Questo repository è **pubblico**: tutto quello che scrivi o alleghi è visibile a chiunque.
Non inserire email, numeri di telefono, chiavi di licenza o altri dati personali.
La diagnostica di Karakara nasconde già il percorso della tua cartella utente.

*This repository is **public**: everything you write or attach can be seen by anyone. Do not include emails, phone numbers, license keys or other personal data. Karakara's diagnostics already hide the path of your user folder.*

## Contatti / Contact

Per questioni private (licenza, acquisto, account) scrivi a **[support@karakara.dev](mailto:support@karakara.dev)**, non aprire una issue.
*For private matters (license, purchase, account) write to **[support@karakara.dev](mailto:support@karakara.dev)** instead of opening an issue.*
